# Growth Market — Stage 1

Это статический frontend-прототип сайта-магазина продвижения Telegram-каналов.

## Что работает
- Адаптивная главная страница.
- Каталог услуг.
- Переход от карточки услуги к форме.
- Валидация полей браузером.
- Демонстрационное создание номера заявки.

## Что пока НЕ подключено
- Сервер и база данных.
- Реальная отправка заявки.
- Платежи.
- API исполнителей.
- Личный кабинет / защищённая страница статуса.

## Как посмотреть
Самый простой способ — загрузить папку на статический хостинг (например, Netlify Drop) или открыть `index.html` в браузере.
Для дальнейшей разработки потребуется перенести frontend на Next.js и добавить backend.

Важно: не вводите реальные персональные данные в демо-форму — сейчас данные никуда не отправляются.
